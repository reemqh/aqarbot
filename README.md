- AqarBot

- Project Overview

AqarBot is an AI-powered real estate chatbot designed to help users find suitable properties through natural language conversations. The system provides personalized recommendations based on user preferences such as budget, location, number of rooms, and desired amenities.

- Features

-User Registration and Login
-AI-powered chatbot for property assistance
-Personalized property recommendations
-User-friendly web interface
 -Real estate information support
-Property search based on user requirements

- Technologies Used :

* Python
* Flask
* HTML
* CSS
* JavaScript
* Groq API
* Llama 3.1 Model
